# Consultorio dental demo

Prototipo web de gestión de citas para un consultorio dental. Es una demo: los datos son de prueba y los recordatorios son simulados; no usar con datos de pacientes reales.

**Estado:** demo publicada en GitHub Pages: https://arteduro.github.io/consultorio-dental-demo/. Pendiente configurar EmailJS para el envío real de correos.
